# Selenium Capstone Project

## Project Title
Automated E-Commerce Purchase Testing using Selenium WebDriver with Python

## Project Overview
This project automates an e-commerce purchase workflow using Selenium WebDriver with Python.

The automation covers browser launch, user login, product search, adding a product to the cart, updating the quantity, verifying cart details, handling alerts/pop-ups, capturing screenshots, and generating an execution report.

## Application Under Test
TutorialsNinja Demo E-Commerce Website

## Technologies Used
- Python
- Selenium WebDriver
- PyTest
- Page Object Model (POM)
- JSON Test Data
- HTML Reporting

## Project Structure

- `pages/` – Page Object Model classes
- `tests/` – Test cases
- `test_data/` – Test data
- `utilities/` – Utility functions
- `screenshots/` – Execution screenshots
- `reports/` – Execution reports
- `conftest.py` – PyTest configuration and fixtures
- `requirements.txt` – Required Python packages
- `test_first.py` – Initial test script

## Test Scenario
1. Launch the browser.
2. Open the e-commerce website.
3. Login using test credentials.
4. Search for the required product.
5. Add the product to the cart.
6. Update the product quantity.
7. Verify the cart details.
8. Handle alerts/pop-ups where required.
9. Capture screenshots.
10. Generate the execution report.

## Test Execution Result
The automation test was executed successfully using PyTest.
